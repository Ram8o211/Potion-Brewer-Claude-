# Hutch — source art

`pen.png` (1672 × 941): the picture the colony's pen was once cut from.

The game no longer uses it: the Moon Rabbits' hutch is painted
procedurally like every other enclosure (`src/visual/env/pens.js`, the
`rabbit` pen — a wire-fenced run with a hay rack and a hutch on legs). It
is kept here for reference only.
